## 원칙
- 값을 직접 쓰지 말고 역할(Semantic)로 부른다. 아래 팔레트 밖의 색·크기·그림자를 새로 만들지 않는다.
- 서체는 Pretendard 하나. 텍스트는 6단계 위계에서만 고른다.
- 모든 간격은 4px의 배수. 라운드는 5단계, 그림자는 3단계에서만 고른다.
- 모바일 웹뷰 기준: 화면 좌우 패딩 16px, 하단 고정 CTA는 가로 100%.

## Spacing (4px 배수)
4px — 아이콘-텍스트 최소 간격
8px — 밀접한 요소 사이 (뱃지 나열)
12px — 리스트 아이템 내부
16px — 기본 화면 좌우 패딩 · 요소 간 기본 간격
20px — 카드 내부 패딩 (SkelCard 기본)
24px — 섹션 내부 블록 간격
32px — 섹션과 섹션 사이
40px — 큰 단락 전환
48px — 히어로 · 페이지 상하 여백

## Radius
radius.sm: 8px — 인라인 태그 · 작은 컨트롤
radius.md: 12px — 입력 필드 · 리스트 아이템
radius.lg: 16px — 버튼 (SkelButton 기본)
radius.xl: 20px — 카드 (SkelCard 기본) · 시트

## Components (@skel-frontend/design-system)
SkelButton — 행동 유도.
  variant: 'primary'(브랜드 배경) | 'secondary'(보더) | 'ghost'(배경 없음), 기본 primary
  isExpanded(가로 100%), isLoading(스피너), disabled(opacity 0.3), height 기본 56, borderRadius 기본 16
  규칙: 한 화면에 primary는 하나. 보조 액션은 secondary/ghost.
SkelCard — 콘텐츠 블록.
  variant: 'outlined'(보더) | 'filled'(옅은 배경) | 'elevated'(그림자), 기본 outlined
  padding 기본 20, radius 기본 20. 규칙: 그림자와 보더를 동시에 쓰지 않는다.
SkelBadge — 상태 표시 필(pill).
  tone: 'brand' | 'neutral' | 'success' | 'warning' | 'error', 기본 neutral
  variant: 'weak'(옅은 배경) | 'solid'(채운 배경), 기본 weak
  규칙: 색을 직접 만들지 않고 tone으로 고른다. 같은 상태 = 같은 tone.
SkelSection — 페이지 골격.
  title(필수), description?, action?(우측 슬롯), children
  규칙: 섹션 사이 간격 32px, 한 섹션 = 한 주제, 제목은 Heading(18px SemiBold) 위계.

## 사용 예
import { SkelButton, SkelCard, SkelBadge, SkelSection } from '@skel-frontend/design-system';

<SkelSection title="참여 방법" description="3단계면 끝나요">
  <SkelCard>
    <SkelBadge tone="success">진행 중</SkelBadge>
    <p>고속도로 충전소에서 첫 충전 시 크레딧으로 돌려드려요</p>
  </SkelCard>
</SkelSection>
<SkelButton isExpanded>이벤트 참여하기</SkelButton>
