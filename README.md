# 전류 잇기 (Circuit Connect)

같은 색 단자를 드래그로 이어서 보드의 모든 칸을 채우는 라인 퍼즐 게임입니다.
충전 대기 시간 같은 짧은 틈에 즐기도록 만든 모바일 우선 미니게임으로,
의존성 없는 **단일 HTML 파일**로 동작합니다.

## 플레이

👉 **https://ian939.github.io/circuit-connect/**

또는 `index.html`을 브라우저에서 그냥 열면 됩니다.

## 규칙

- 같은 색 단자 두 개를 드래그해서 연결합니다.
- 선끼리 교차할 수 없습니다.
- **모든 색을 연결하고 빈칸을 하나도 남기지 않아야** 스테이지가 클리어됩니다.
- 클리어할 때마다 보드가 커지고 색이 늘어나며 포인트가 적립됩니다.

## 특징

- 레벨 생성기가 해밀턴 경로(zig-zag + backbite 셔플)를 잘라 색을 배정하므로 **항상 정답이 존재하는 판**만 나옵니다.
- 마우스·터치 모두 지원 (포인터 이벤트).
- 스테이지별 난이도 자동 상승, 포인트 적립 UI.
- `prefers-reduced-motion` 대응.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 전체 (HTML + CSS + JS 단일 파일) |

외부 의존성은 Google Fonts(Space Grotesk, IBM Plex Mono)뿐이며, 오프라인에서도 시스템 폰트로 정상 동작합니다.
