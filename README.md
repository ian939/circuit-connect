# 전류 잇기 (Circuit Connect)

같은 색 단자를 드래그로 이어서 보드의 모든 칸을 채우는 라인 퍼즐 게임입니다.
충전 대기 시간 같은 짧은 틈에 즐기도록 만든 모바일 우선 미니게임으로,
의존성 없는 **단일 HTML 파일**로 동작합니다.

## 플레이

👉 **https://ian939.github.io/circuit-connect/**

또는 `index.html`을 브라우저에서 그냥 열면 됩니다.

## 규칙

- 같은 색 단자 두 개를 드래그해서 연결합니다.
- 선끼리 교차할 수 없습니다.
- **모든 색을 연결하고 빈칸을 하나도 남기지 않아야** 클리어됩니다.

## 모드

### 1. 온보딩 (1~10단계)

튜토리얼 겸 실력 확인 구간. 5×5 / 4색에서 시작해 단계마다 보드와 색이 늘어납니다.
**10단계를 통과하면 데일리 챌린지가 해금**되고, 이후 온보딩 탭은 무제한 연습 모드로 남습니다.

### 2. 데일리 챌린지 (매일 3판)

| # | 이름 | 보드 |
| --- | --- | --- |
| 1 | 워밍업 | 6×6 · 5색 |
| 2 | 러시아워 | 7×7 · 6색 |
| 3 | 과부하 | 8×8 · 8색 |

- **판이 열리는 순간부터 시간이 카운트**되고, 완주 시간이 그날의 기록으로 남습니다.
- 랭킹은 **최단 시간 순**. 재도전하면 더 빠른 기록으로 갱신됩니다.
- 순위 보너스 포인트는 그날 **첫 완주 1회**만 지급됩니다.
- 매일 자정에 새 문제 3개로 초기화됩니다.

## 특징

- 레벨 생성기가 해밀턴 경로(zig-zag + backbite 셔플)를 잘라 색을 배정하므로 **항상 정답이 존재하는 판**만 나옵니다.
- 챌린지는 `날짜 + 챌린지 번호`를 시드로 쓰는 결정적 난수(mulberry32)로 생성됩니다.
  → **같은 날이면 누구에게나 똑같은 문제**가 나오므로 기록 비교가 공정합니다.
- 진행도·기록은 `localStorage`에 저장됩니다 (`circuit-connect.v1`).
- 마우스·터치 모두 지원. 태블릿 롱프레스 시 뜨는 복사/잘라내기 콜아웃 차단.
- `prefers-reduced-motion` 대응.

## 서버 연동 지점

지금은 프론트만 있는 프로토타입입니다. 실제 서비스로 넘길 때 손댈 곳:

| 위치 | 할 일 |
| --- | --- |
| `awardPoints(pts)` | 충전 세션 검증 후 포인트 적립 API 호출 |
| `NAMES` / `ME` | 로그인 사용자 정보로 교체 |
| `botTimes()` | 실제 랭킹 조회 API로 교체 |
| `winChallenge()` | 기록 제출 API 호출 추가 |
